## Contribution Policy

Viña Raíces Winery is proprietary portfolio work.

Unsolicited code contributions, modifications, redistribution, or derivative commercial use are not authorized without prior written permission.

Feedback and issue reports may be submitted when repository functionality permits.

---

## Reporting Problems

When reporting a technical problem, provide:

- Clear problem description
- Steps to reproduce
- Browser and version
- Device or viewport size
- Expected behavior
- Actual behavior
- Console errors
- Screenshot when useful
- Relevant file or component

---

## Development Standards

Changes should preserve:

- Semantic HTML5
- Responsive behavior
- Accessibility
- Existing visual identity
- Organized asset structure
- Readable CSS
- Maintainable JavaScript
- Existing project architecture

---

## HTML Standards

HTML should:

- Use semantic elements
- Maintain logical heading hierarchy
- Include meaningful `alt` attributes
- Use accessible labels
- Avoid unnecessary ARIA
- Maintain valid document structure

---

## CSS Standards

CSS should:

- Use the existing design system
- Preserve responsive behavior
- Use readable selectors
- Avoid unnecessary overrides
- Maintain existing visual proportions
- Use responsive units when appropriate
