# Security Policy

## Viña Raíces Winery

Viña Raíces Winery is a front-end portfolio project.

The current project does not provide:

- Production authentication
- User accounts
- Payment processing
- Customer databases
- Production APIs
- Private customer information storage

---

## Supported Version

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Development / Main | Yes |
| Older versions | No |

---

## Reporting a Security Issue

Security issues should be reported privately to the project owner whenever possible.

Do not publicly disclose a vulnerability before it has been reviewed.

---

## Security Report Information

A report should include:

- Description
- Affected component
- Steps to reproduce
- Potential impact
- Browser or environment
- Suggested remediation when available

---

## Do Not Include

Do not include unnecessary:

- Passwords
- Authentication credentials
- Private personal information
- Security tokens
- API keys
- Environment secrets

---

## Current Security Scope

Security considerations for this project primarily include:

- Client-side JavaScript
- DOM manipulation
- Form handling
- Input handling
- External resources
- Browser behavior
- Third-party dependencies
- Deployment configuration

---

## Front-End Form Notice

The newsletter form is a front-end demonstration.

It does not currently transmit subscriber information to a production mailing database.

Any future production implementation must introduce appropriate server-side validation, secure transport, data protection, and privacy controls.

---

## Future Production Security

If the project is converted into a production application, additional controls should be evaluated, including:

- HTTPS
- Content Security Policy
- Server-side validation
- Authentication
- Authorization
- Secure session management
- Database security
- API security
- Rate limiting
- Dependency management
- Logging
- Monitoring
- Backup strategy
- Privacy controls

---

## Responsible Disclosure

Security vulnerabilities should be disclosed responsibly and privately whenever possible.

The project owner reserves the right to determine the appropriate remediation and disclosure timeline.
