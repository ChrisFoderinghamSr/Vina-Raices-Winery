# Viña Raíces Winery

**Panamanian Grapes. Deep-Rooted Heritage. A Family Secret for Taste.**

Viña Raíces Winery is Project 2 in the Christian Foderingham Software Development Portfolio.

The project is a responsive front-end website concept for a fictional premium Panamanian winery centered around family heritage, vineyard craftsmanship, generational knowledge, and luxury wine presentation.

---

## Project Information

**Project:** Viña Raíces Winery  
**Portfolio Project:** Project 2  
**Project Type:** Responsive Front-End Website  
**Version:** 1.0.0  
**Status:** Final Portfolio Release  
**Primary Technologies:** HTML5, CSS3, JavaScript

## Hero

## Our Story

The Our Story section introduces the fictional family estate.

Primary message:

**Rooted in Panama. Driven by Family.**

The section uses estate photography and introduces the relationship between the family, the land, and the wine.

## Our Wines

The wine collection contains five fictional Viña Raíces wines:

1. Reserva Familiar
2. Selección de Raíces
3. Herencia Blanco
4. Rosado de Familia
5. Gran Reserva

Each wine includes:

- Wine category
- Product name
- Description
- Bottle image
- View Profile interaction
