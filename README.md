# Viña Raíces

## Panamanian Wines

### Panamanian Grapes. Deep-Rooted Heritage.

Viña Raíces is a fictional premium winery website concept created as Project 2 in Christian Foderingham's software development portfolio.

The project is designed to demonstrate modern front-end development, responsive design, semantic HTML5, CSS Grid, Flexbox, accessibility, JavaScript interaction, and professional project organization.

## Project Status

**Phase:** Project Foundation

**Version:** 0.1.0

**Status:** In Development
